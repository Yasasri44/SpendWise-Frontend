A modern expense tracking web application with analytics and visual insights.

---

## 🚀 Features

- Add & delete expenses
- Category-wise spending (Pie Chart)
- Daily spending analysis (Bar Chart)
- Spending Heatmap 📊
- Clean and responsive UI

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js
- Cal-Heatmap
